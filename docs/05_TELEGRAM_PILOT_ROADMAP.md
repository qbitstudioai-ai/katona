- ✅ Создать закрытую служебную супергруппу Telegram и включить темы (подтверждено пользователем).
- ✅ Служебный Telegram-бот Катоны добавлен в закрытую группу администратором (пользователь подтвердил). Конкретные права проверить при тесте.
- ✅ ID закрытой группы определён по ссылке на тестовое сообщение; конкретное значение хранится только в приватных настройках.
- ✅ Проверено: из временного Workflow n8n служебный Telegram-бот успешно отправляет сообщения в свою закрытую группу; API вернул `ok: true`, `type: supergroup`, `is_forum: true`.
- 🔄 Проверить входящие Telegram Webhook, права на создание тем и список допущенных тестировщиков. Старый Qbit Telegram-bridge не использовать.
- ⬜ Согласовать, будет ли служебная группа и загрузка базы знаний обслуживаться **отдельным** Telegram-ботом (как в Qbit), или тем же ботом; для безопасности предпочтителен отдельный.
- ⬜ Подготовить два n8n JSON на основе Qbit с заменой схемы SQL на `katona`, кодом компании `katona`, новыми Telegram и Postgres Credentials, уникальными webhook и настройками Катоны; сохранить `active=false`.
- ⬜ Внести четыре сценария: розница, подрядчик, тендер, сервис. Не озвучивать неподтверждённые цены и не подтверждать замер/заявку без фактического создания.
- ⬜ Подготовить и загрузить проверенные знания Катоны через служебный Workflow (векторы 1024); не копировать знания Qbit.
- ⬜ Настроить ограниченный список тестировщиков, закрытый доступ к боту, отсутствие публичной ссылки и рассылок. Telegram-бот может получать сообщения от знающих username: **проверять Telegram user_id на входе**, а не рассчитывать только на непубличность ссылки.
- ⬜ Проверить запрос менеджера, передачу в служебную группу, ответы/возврат, память, заявки, голос/фото и запреты повторных сообщений.
- ⬜ Дать заказчику провести тестирование **только собственными силами**, не передавать бота настоящим покупателям.
- ⬜ Согласовать результаты и устранить замечания; публичный запуск — отдельное разрешение.
